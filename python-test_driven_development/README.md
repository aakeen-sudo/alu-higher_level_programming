\# Python - Test-driven development



This project covers writing Python functions using test-driven development (TDD),

including docstrings, doctests, and PEP8-compliant code.



\## Files



\- `0-add\_integer.py`: adds two integers, casting floats to int, with type checking.

\- `tests/0-add\_integer.txt`: doctest file for `0-add\_integer.py`.
