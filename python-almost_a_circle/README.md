# Almost a Circle

This project is a Python OOP exercise building a Rectangle and Square
class hierarchy, based on a Base class that manages a unique id for
every instance created.

## Files

- models/base.py: Base class managing id
- models/rectangle.py: Rectangle class (inherits Base)
- models/square.py: Square class (inherits Rectangle)
- tests/: Unit tests for all classes

## Usage

Run all tests with: python3 -m unittest discover tests
